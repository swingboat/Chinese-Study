### 二、知识点详细梳理

#### 复习巩固的知识点

- **文言虚词“因”**：今天能区分“于是、就”和“趁机、趁着”。“相如因持璧却立”表示动作承接，译为“于是、就”；“沛公起如厕，因招樊哙出”强调借离席机会行动，译为“趁机、趁着”。

#### 新学知识点

- **虚词“之”的高频用法**：
  1. 结构助词“的”：古之学者。
  2. 代词：知之，代指知识、道理或前文事物。
  3. 动词“到、往、去”：辍耕之垄上。
  4. 定语后置标志：爪牙之利、筋骨之强、马之千里者。
  5. 主谓之间取消句子独立性：臣之壮也、师道之不传。
  6. 宾语前置标志：句读之不知、何陋之有。
  7. 音节助词初识：久之，无实义。

- **宾语前置三类**：
  1. “宾语 + 之/是 + 动词”：何陋之有、何厌之有、何罪之有。
  2. 否定句中代词作宾语前置：不余欺、未之有。
  3. 疑问句中疑问代词作宾语前置：沛公安在、大王来何操。

- **状语后置/介词结构后置入门**：
  文言中“于 + 对象/地点/范围”常放在动词或形容词后，翻译时要调到前面。如“善假于物”应理解为“善于借助外物”，“于物”是介词结构，翻译时应放到“假”前面来理解。今天选择和调序判断均正确，后续需要放入“青于蓝、取之于蓝”等句子中迁移。

#### 专项强化技能

- 判断“之”时不能只凭“能不能译成的”，要看结构：
  - “名词 + 之 + 形容词”常是定语后置。
  - “主语 + 之 + 谓语”常是主谓之间取消独立性。
  - “宾语 + 之 + 动词”常是宾语前置标志。
- 判断宾语前置时必须完整提取宾语，如“何厌之有”提前的是“何厌”，不是只写“厌”。

### 三、易错点汇总

- **“庙堂之高/江湖之远”误判为普通“的”**：应识别为定语后置标志。状态：✅纠错后理解，需混合复查。
- **宾语成分提取不完整**：“何厌之有”提前的是“何厌”，不是单独“厌”。状态：✅通过“何罪之有”纠正。
- **状语后置调序点**：“善假于物”选择和调序均正确，状态：✅入门通过；因属于新学句式，仍需+1天迁移复查。

## 学习内容

### 知识点1：文言虚词“因”复习

**学生初始理解**:

- 已学过“因”的“于是/就、趁机/趁着、凭借/通过、因为/由于”等用法。

**讲解内容**:

- “因”要结合前后动作关系判断：动作自然承接，多译“于是、就”；借某个机会行动，多译“趁机、趁着”。

**理解检查**:

- “相如因持璧却立”选B，“于是、就”。
- “沛公起如厕，因招樊哙出”选D，“趁机、趁着”。
- 结果：✅ 两题全对。

**掌握程度**: 🟢 已掌握，后续放入陌生文言小段迁移

### 知识点2：虚词“之”的高频用法

**学生初始理解**:

- 能识别“蚓无爪牙之利，筋骨之强”中的“之”为定语后置标志；但曾把“庙堂之高，江湖之远”误判为普通“的”。

**讲解内容**:

- 系统学习“之”的结构助词、代词、动词、定语后置、主谓之间取消独立性、宾语前置标志、音节助词等用法。
- 重点用结构判断，不机械翻译成“的”。

**理解检查**:

- 学生能正确判断“古之学者”“知之”“之垄上”“臣之壮也”“句读之不知”“久之”等用法。
- 结果：✅ 绝大多数判断正确；“庙堂之高”经纠错后理解。

**掌握程度**: 🟡 基本理解，需混合复查

### 知识点3：宾语前置

**学生初始理解**:

- 通过“句读之不知，惑之不解”初步认识“之”可作宾语前置标志。

**讲解内容**:

- 三类高频宾语前置：
  1. “宾语 + 之/是 + 动词”：何陋之有。
  2. 否定句中代词作宾语：不余欺、未之有。
  3. 疑问句中疑问代词作宾语：沛公安在、大王来何操。

**理解检查**:

- 学生能判断“何陋之有”“何罪之有”“不余欺”“未之有”“沛公安在”“大王来何操”等句式。
- “何厌之有”中最初只答“厌”，后经提示能通过“何罪之有”纠正为完整宾语“何罪”。

**掌握程度**: 🟢 基本掌握，需在翻译题中训练完整表述
