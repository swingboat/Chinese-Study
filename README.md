# Chinese-Study 高考语文备考

🎯 **目标**: 2027年安徽高考语文

这是一个使用 AI 辅助的高考语文备考学习环境，采用引导式学习方法。

## 项目结构

```
/progress/
  chinese-study-tracker.md  ← 学习进度追踪
/sessions/
  /YYYY-MM-DD/             ← 每日学习记录
    session-notes.md
  SESSION-TEMPLATE.md      ← 学习记录模板
/教材资料/
  统编版·语文必修 上册.pdf
  统编版·语文必修 下册.pdf
  统编版·语文选择性必修 上册.pdf
  统编版·语文选择性必修 中册.pdf
  统编版·语文选择性必修 下册.pdf
/.github/
  copilot-instructions.md  ← AI 导师指令
```

## 学习方法

本项目采用以下学习方法：

1. **苏格拉底式教学** - 通过提问引导理解
2. **艾宾浩斯复习** - 科学的复习间隔
3. **错题引导纠正** - 自己发现并改正错误
4. **充分练习** - 每个知识点5-8道题

## 开始学习

直接和 Copilot 开始对话，例如：
- "我想学习文言文虚词'而'的用法"
- "给我出几道诗歌鉴赏的练习题"
- "帮我复习今天到期的内容"
- "检查我的名篇名句默写"
